# PlayBook

Audiobook player built with Python, Flet, and SQLite.

## Features
- Scan folders and detect audiobooks (MP3, M4B, FLAC, OGG, etc.)
- Library with list/grid views, cover art, and progress bars
- Playback controls: speed, seek (±15s), sleep timer with fade-out
- Playlist queue and persistent mini-player
- Track position saved automatically
